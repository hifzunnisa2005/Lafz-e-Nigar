# Font Import Guide - لفظ نگار

## Overview
Lafz-Nigar now supports multiple fonts and custom font imports! You can use pre-installed fonts or upload your favorite Urdu fonts.

## Pre-installed Fonts
The following fonts are available by default:
- **Noto Nastaliq Urdu** - Google's beautiful Nastaliq font
- **Noto Sans Arabic** - Clean, modern Arabic script
- **Amiri** - Classical Arabic typeface
- **Scheherazade New** - Traditional style with excellent Unicode support
- **Lateef** - Compact Nastaliq style

## How to Import Custom Fonts

### Step 1: Get Your Font File
Download Urdu font files in one of these formats:
- `.ttf` (TrueType Font)
- `.otf` (OpenType Font)
- `.woff` (Web Open Font Format)
- `.woff2` (Web Open Font Format 2)

### Step 2: Import the Font
1. Click the **Upload icon** (⬆️) next to the Font dropdown in the toolbar
2. Click **"Import Font File"** button
3. Select your font file from your computer
4. Wait for the import to complete

### Step 3: Use Your Font
- Your custom font will appear in the Font dropdown
- Custom fonts are marked with a star (⭐)
- Select it to start using it in your document

## Managing Custom Fonts

### View Custom Fonts
Click the Upload icon to see all your imported fonts

### Delete a Font
1. Click the Upload icon
2. Find the font you want to remove
3. Click the trash icon (🗑️) next to it
4. Confirm deletion

## Technical Notes

- Custom fonts are stored in your browser's localStorage
- Fonts persist across sessions on the same browser
- Maximum recommended file size: 5MB per font
- Fonts work offline after import
- PDF exports use the selected font

## Troubleshooting

**Font not displaying correctly?**
- Ensure the font file is not corrupted
- Try a different font format (.ttf usually works best)
- Clear browser cache and re-import

**Font disappeared?**
- Check if localStorage was cleared
- Re-import the font file

**Characters appearing as boxes?**
- The font may not support all Urdu characters
- Try a different font with better Unicode coverage

## Tips for Best Results

1. Use Nastaliq fonts for traditional Urdu writing
2. Naskh fonts work well for formal documents
3. Test fonts with sample text before using extensively
4. Keep font files organized in a dedicated folder
5. Use higher font sizes (18-24px) for better readability
