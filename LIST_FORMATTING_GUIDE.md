# List Formatting Guide - لفظ نگار

## Overview
Lafz-Nigar now supports comprehensive list formatting with bullet points and numbered lists, perfect for organizing your Urdu content.

## Quick Start

### Creating a Bullet List
1. Click the **List icon** (☰) in the toolbar
2. Start typing your first item
3. Press **Enter** to create a new bullet point
4. Press **Enter** twice to exit the list

### Creating a Numbered List
1. Click the **Numbered List icon** (1-2-3) in the toolbar
2. Start typing your first item
3. Press **Enter** to create a new numbered item
4. Press **Enter** twice to exit the list

## Indentation

### Increase Indent
- Click the **Indent icon** (→) to move the item to the right
- Useful for creating sub-items and nested lists
- Keyboard shortcut: **Tab** key

### Decrease Indent
- Click the **Outdent icon** (←) to move the item to the left
- Returns to the previous level
- Keyboard shortcut: **Shift + Tab**

## List Features

### Bullet Lists
Create unordered lists with various bullet styles:
- **Disc** (●) - Default style
- **Circle** (○) - Hollow circle
- **Square** (■) - Square bullet
- **Arabic Bullet** (•) - Traditional bullet point

### Numbered Lists
Create ordered lists with different numbering systems:
- **Numbers** (1, 2, 3) - Standard decimal
- **Zero-padded** (01, 02, 03) - With leading zeros
- **Lowercase** (a, b, c) - Alphabetical
- **Uppercase** (A, B, C) - Capital letters
- **Roman Lower** (i, ii, iii) - Roman numerals lowercase
- **Roman Upper** (I, II, III) - Roman numerals uppercase
- **Arabic-Indic** (١, ٢, ٣) - Eastern Arabic numerals

## Nested Lists

You can create multi-level lists:

### Example 1: Nested Bullet List
```
● Main Point
  ○ Sub-point 1
  ○ Sub-point 2
    ■ Sub-sub-point
● Another Main Point
```

### Example 2: Nested Numbered List
```
1. First item
   a. Sub-item A
   b. Sub-item B
2. Second item
```

## RTL (Right-to-Left) Support

All lists automatically support RTL layout for Urdu:
- Bullets appear on the right side
- Text flows from right to left
- Numbers and markers maintain proper direction
- Perfect alignment with Urdu text

## Formatting Within Lists

You can apply formatting to list items:
- **Bold** text in lists
- *Italic* text in lists
- Underlined text in lists
- Different colors and fonts
- Different font sizes

## Tips for Best Results

1. **Use appropriate list type**
   - Bullet lists for unordered items
   - Numbered lists for sequential steps or rankings

2. **Keep items concise**
   - One idea per list item
   - Break long items into sub-items

3. **Use indentation wisely**
   - Maximum 3 levels deep
   - Maintain visual hierarchy

4. **Mix list types**
   - Combine bullets and numbers for complex structures
   - Use different numbering styles for different sections

## Exporting Lists

When you export to PDF or TXT:
- Lists maintain their formatting
- Indentation is preserved
- Bullets and numbers are rendered correctly
- RTL direction is maintained

## Troubleshooting

**Lists not aligning correctly?**
- Ensure RTL mode is enabled
- Check your font supports list markers
- Try refreshing the page

**Can't indent/outdent?**
- Make sure cursor is inside a list item
- Use toolbar buttons instead of Tab if needed

**Numbers appearing backwards?**
- This is normal for RTL text
- The direction is correct for Urdu

**Bullets disappearing?**
- Click the list button again to toggle
- Check if content was accidentally deselected
